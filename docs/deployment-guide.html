Arkline Home & Office Furniture · deployment guide

Putting the website live

Follow these steps once the client has paid and is ready to buy the domain. The website is finished and tested; this is only about putting it on the internet. Total time: about one hour. Total cost: about ₱600 a year for the domain. Everything else is free.

Before you start

Have these ready

  • Payment settled with the client. Hand over logins only after this.
  • The company Gmail (arklinefurniture3@gmail.com) and its password. Every account is made with this email, so the client owns everything.
  • The client's card (or PayPal) to pay for the domain.
  • The owner's phone nearby, for Google's sign-in codes.
  • Your project folder with the .env.local file. It holds the keys you will copy in Step 3.
  • The latest code on GitHub: run git push client main in the project folder. The repo is arklinefurniture3-boop/arklinefurniture-main.
Step 1 · about 10 min

Create the Cloudflare account company Gmail

  1. Go to dash.cloudflare.com and sign up with the company Gmail.

  2. Open the company Gmail and click the verify your email link from Cloudflare. Domains can't be bought until the email is verified.

  3. Turn on 2-step verification: profile icon (top right) → Profile → Authentication.

  4. Add the client's card: Manage Account → Billing → Payment info.

Step 2 · about 10 min

Buy the domain client's card

  1. In Cloudflare, go to Domain Registration → Register Domains.

  2. Search arklinefurniture.com. If it's taken, use arklineofficefurniture.com or arklinefurnitureph.com.

  3. Buy it for 1 year and leave auto-renew ON, so the website never goes down because the domain expired. Privacy is free and on by default.

Says "unavailable" but the name is free? The email isn't verified yet, no card is saved, or the account is too new. Fix the first two and wait an hour. If it still fails, buy at porkbun.com (same price) and then point it at Cloudflare.

Step 3 · about 15 min

Put the site on Cloudflare Pages

  1. Cloudflare → Compute → Workers & Pages → Create. Don't use "Connect GitHub" on that screen (it makes a Worker); click Continue to Pages at the very bottom, then Import an existing Git repository.

  2. Sign in to GitHub as arklinefurniture3-boop, allow access to arklinefurniture-main, and select it.

  3. Project name: arklineofficefurniture. Framework preset: None. Build command: npm run build. Build output directory: dist.

  4. Open Environment variables (advanced) and add each line from the table below before deploying. Copy the values from your .env.local. Added them later? Go to Settings → Variables and Secrets, add them there, then Deployments → ⋯ → Retry deployment: keys only take effect in a new build.

  5. Click Save and Deploy. After about 1 minute the site is live at arklineofficefurniture.pages.dev. The address may differ slightly if "arkline" is taken; note the one Cloudflare shows.

Step 4 · about 5 min

Connect the domain

  1. In the Pages project, open Custom domains → Set up a custom domain.

  2. Enter arklinefurniture.com and confirm. Do the same for www.arklinefurniture.com.

  3. Wait a few minutes until both show Active. The padlock (HTTPS) is set up automatically and is free.

Step 5 · about 5 min · don't skip

Tell Supabase the new address

Without this, Google sign-in and "Forgot password" send the admin back to localhost instead of the live site.

  1. Open supabase.com → the Arkline project → Authentication → URL Configuration.

  2. Site URL: https://arklinefurniture.com

  3. Redirect URLs: add https://arklinefurniture.com/** and https://arklineofficefurniture.pages.dev/**. Keep the localhost one for testing.

  4. Click Save.

Step 6 · about 10 min

Turn on email alerts (Resend) company Gmail

  1. Sign up at resend.com with the company Gmail. Free: 3,000 emails a month.

  2. Domains → Add domain → arklinefurniture.com. Resend shows a few records to add. Choose the option to add them to Cloudflare automatically, or copy each one into Cloudflare → the domain → DNS → Records. Wait until Resend says Verified.

  3. API Keys → Create API Key and copy it (starts with re_).

  4. In Cloudflare Pages → Settings → Variables and Secrets, add:
    RESEND_API_KEY = the key (Encrypt it)
    NOTIFY_FROM = Arkline Website <orders@arklinefurniture.com>

Step 7 · about 5 min

Turn on the spam check (Turnstile)

  1. Cloudflare → Turnstile → Add widget. Name: Arkline. Hostnames: arklinefurniture.com and arklineofficefurniture.pages.dev. Mode: Managed.

  2. Copy the two keys into Pages → Settings → Variables and Secrets:
    VITE_TURNSTILE_SITE_KEY = the Site Key
    TURNSTILE_SECRET_KEY = the Secret Key (Encrypt it)

  3. Go to Deployments, then open the latest one and click Retry deployment, so the new settings are used.

Step 8 · about 10 min

Test the live site

  • Open https://arklinefurniture.com on a phone. The padlock shows, and photos, shop and prices load.
  • Send a price request with your own number. The success message shows a request number.
  • The company Gmail receives the alert email within a minute (check Spam the first time).
  • Open https://arklinefurniture.com/admin and sign in with Google. The request is there.
  • Sign out, then sign in with email and password. Try Forgot password; the link must open the live site, not localhost.
  • Upload one photo. It shows in the website gallery within about 30 seconds. Then move your test request and test photo to Trash.
Step 9 · about 10 min

Hand over to the client

  • Supabase → Organization → Team → Invite the company Gmail as Owner, so the client controls the database too.
  • Give the owner the Admin guide (PDF) and the admin address: arklinefurniture.com/admin.
  • Write down for the owner which accounts use the company Gmail: Cloudflare, Resend, Supabase, GitHub. Add the domain renewal date (one year from today) to their calendar.
  • Ask the owner to change the Gmail password after you finish, so only they can get in.
After launch

Updating the website later

  1. Make the change in the project folder and check it on localhost:5173.

  2. Commit, then run git push client main.

  3. Cloudflare rebuilds and updates the live site by itself in about a minute.
