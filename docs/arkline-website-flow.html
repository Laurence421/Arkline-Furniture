How an order gets from the customer to Arkline

Customers order from the shop or ask for a price on custom work, with no account needed. Every request is saved, emailed to Arkline and shows up in the admin page, where the team replies and keeps the website up to date themselves.

When a customer orders or asks for a price

  1. 1

    Browses the website. Sees the project gallery with "starts at" prices and the shop with current prices. No sign-up.

  2. 2

    Picks what they want. Add to order for shop items, I want one like this on a project photo, or simply describes custom work.

  3. 3

    Sends the form. It reads "Send my order" or "Ask for a price" to match. Name, mobile or email, how to contact them (call or text, Viber, Messenger, email) and an optional photo.

  4. 4

    The request is checked and saved. The total is worked out from Arkline's own price list, so it can't be faked. The customer sees their number, e.g. "Your order #12 is in."

  5. 5

    Their photo is stored privately. Only Arkline can open it; the public can't.

  6. 6

    An alert email lands in Arkline's Gmail with the items, total, liked photos and how the customer wants to be contacted.

  7. 7

    Arkline replies within one business day, the way the customer asked: call, text, Viber, Messenger or email.

When the admin works on requests and the site

  1. A

    Opens the admin page and signs in with Google (one click) or email and password. "Forgot password?" sends a reset link.

  2. B

    Sign-in is checked against the admin list. Any other account sees "Not an admin account".

  3. C

    Answers requests. Each one is labelled Order or Price request, with one-tap Call, Text, Viber, Messenger and Reply in Gmail (a drafted reply). Status and private notes keep track.

  4. D

    Updates the website. Uploads or removes project photos, changes prices and products, edits the words on the site.

  5. E

    Changes show on the website within 30 seconds. Anything deleted can be restored, and every delete asks first.

What's in the admin page

Five tabs. Everything the team needs to run the website without a developer.

Requests daily

Orders and price requests, newest first. Filter by status, search by name, phone or number, reply in one tap, keep private notes.

Photos

Upload project photos from a phone; they're shrunk automatically. Delete moves a photo to Trash, where it can be restored.

Prices

Edit names, prices and features, add a photo, hide or delete items, add new chairs and tables. Set "starts at" prices for each project type.

Website text

Headline, services, how to order, FAQs, contact numbers, Facebook page and Viber number. "Restore original" undoes a section.

Account

Change the password, add one if you only use Google, or sign out on every device after using a shared computer.

Who can see what

Access rules live in the database itself, so they hold no matter which page asks. A security test tried 32 ways to get in or change things without the admin account; all 32 were blocked.
