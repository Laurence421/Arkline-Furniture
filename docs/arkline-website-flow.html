How a quotation gets from the customer to Arkline

Customers send a quote request from the website without creating an account. It is saved to Arkline's database and emailed to Arkline. The admin manages the project photos from a private admin page.

When a customer asks for a quote

  1. 1

    Browses the website. Sees the project gallery, adds chairs or tables to the quote list. No sign-up.

  2. 2

    Sends the quotation form. Name, mobile or email, project type, a description and an optional reference photo.

  3. 3

    The request is saved. The website checks the details, works out the price estimate from Arkline's own price list, and stores the request.

  4. 4

    The reference photo is stored privately. Only Arkline can open it; the public can't.

  5. 5

    An alert email is prepared with the customer's details, items and estimate.

  6. 6

    It lands in Arkline's Gmail. Replying to it goes straight to the customer's email.

  7. 7

    Arkline replies within one business day by phone or email with the formal quotation, as the form promises.

When the admin updates the gallery

  1. A

    Opens the admin page and signs in with Google (one click) or email and password. "Forgot password?" sends a reset link.

  2. B

    Sign-in is checked against the admin list. Any other account sees "Not an admin account".

  3. C

    Uploads, trashes or restores photos. New photos are shrunk to about 200 KB each before upload, so they load fast.

  4. D

    The public gallery updates right away. Deleted photos sit in Trash and can be restored.

Who can see what

Access rules live in the database itself, so they hold no matter which page asks.
